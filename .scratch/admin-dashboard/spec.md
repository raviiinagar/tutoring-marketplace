# Unified administration workspace

Owner request, 28 October 2026: make an operational admin dashboard the main staff workspace, with a professional consistent layout and all existing staff work reachable inside it. Reuse /staff as the dashboard entry, preserve all scoped workflows and mandatory MFA. REA was optional; its connector is unavailable in this session, so source inspection and Playwright provide runtime verification.

Adopted defaults: first-party anonymous public page/session observations only; no external analytics, raw URLs, query strings, referrers, contacts, IPs or child/private-page payloads in analytics tables. Tab sessions expire after 30 minutes of observed inactivity. Daily salted receipts deduplicate visits/page observations; receipt retention is bounded. Respect browser DNT/GPC. Visits mean observed browser-tab sessions, not unique humans; tracking starts only when deployed and cannot reconstruct historical visitors. Existing signup/login audit facts support historical account reporting.

Overview uses IST 7/30/90-day filters, clear metric definitions, daily trend, current work queues, role-filtered finance, environment labels and redacted activity. Every report rechecks active staff assignment, original account session and MFA; financial aggregates/coupon metrics require FINANCE; private account directory requires SUPPORT, no self-grant or unrestricted mutation. Personal data stays out of audience charts. Existing staff tools share one responsive sidebar/header. Visitor counts before tracking are unavailable, not invented zeroes. Sessions valid now are not presented as online people. Failed fetches/auth expiry clear stale reports.

Routine UI/design choices delegated by owner. No new paid services, live merchant changes or infrastructure extension. Preserve unrelated workspace changes and existing test sandbox isolation. Implement API/real PostgreSQL, UI permission/empty/error checks and hosted browser evidence before considering complete.
