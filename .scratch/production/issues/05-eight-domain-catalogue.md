# 05: Browse and administer the eight-domain catalogue

Status: ready-for-agent
Type: task
Blocked by: 03 — Sign in to a scoped staff console with MFA

**What to build:** A visitor can browse the eight confirmed Learning Domains, while authorised staff maintain Subjects, Learner Levels, Curricula, Exam Tracks and Teaching Languages.

## Acceptance criteria

- [ ] All eight families appear with representative terms, including JEE, NEET, CUET and school-board coverage.
- [ ] Stable identifiers and aliases prevent duplicate exam/subject spellings from fragmenting discovery.
- [ ] Curriculum and Exam Track remain separate from Subject and Teaching Language.
- [ ] Staff can activate/deactivate catalogue terms; unsupported taxonomy values are rejected by API validation.
- [ ] Public/staff integration tests prove consistent catalogues and deny unauthorised edits.
