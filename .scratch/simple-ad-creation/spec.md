# One-form creation from My ads

Owner follow-up, 18 November 2026: creating an ad from My ads still opens the ten-step editor even after the simpler first-Tutor setup was released.

Self-service **Create an ad** must open one form, reuse the saved introduction/rate/photo, and offer preview and a separate explicit publication action. A photo-less draft stays private. Online ads do not require a public city; in-person ads retain the existing coarse location validation. Preserve existing ads, profile/identity/contact settings, teaching availability, server validation and safety/publication rules. Keep optional trial controls and the existing ad-section editor and staff-assisted wizard working.

Use the existing API client and endpoints. No API, migration, payment/access policy, configuration or deployment change belongs to this fix. Relevant decisions: ADR0013, ADR0014, ADR0018 and ADR0019.
