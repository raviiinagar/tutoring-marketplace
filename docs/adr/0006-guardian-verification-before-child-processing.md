# Verify guardian authority before live child-data processing

Serve child Learners through adult Guardian-controlled accounts, with identifiable-adult verification, authority evidence and versioned consent outcomes rather than treating account ownership or payment as sufficient verification. Implement a replaceable verification/staff-review boundary because the approved evidence method and legal applicability must be resolved before live collection, while minimising child fields and keeping child communication adult-controlled. This preserves the accepted child-learning scope without building permanent dependency on unapproved identity-document collection.
