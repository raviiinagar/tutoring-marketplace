# Separate owner administration from delegated review work

On 1 November 2026 the owner requested one Super Admin who can grant/revoke other Admins, with ordinary Admins limited to the referenced review, safety, support and privacy areas. The single owner is selected through trusted server configuration, rather than a transferable web role, to avoid accidental owner lockout or self-promotion. The backend enforces this boundary independently of navigation, preserves purpose-specific and self-review restrictions, audits delegation, and revokes staff sessions when grants change.

The owner also explicitly amended mandatory MFA for the current staging test window. Password reauthentication and short staff sessions remain required; test-password sessions are tagged separately from MFA sessions, stop being usable when the absolute exception deadline passes or configuration disables it, and cannot carry over as MFA authorization. Only specifically named staging environments with no live payment mode can enable the exception, and its configured deadline cannot be more than 72 hours ahead. Existing production MFA and stored authenticators remain intact. The current deadline is the already approved 3 November 2026 10:25:48 UTC; extending compute does not silently extend this exception.
