# Triage labels

The skills use five canonical triage roles. For this project's local Markdown tracker, write the mapped string on each implementation issue's `Status:` line.

| Canonical role | Local tracker string | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for agent implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a triage role, use the corresponding local tracker string. Edit the local tracker column if the project's vocabulary changes.

Wayfinding tickets use their separate lifecycle states as specified in [issue-tracker.md](./issue-tracker.md).
