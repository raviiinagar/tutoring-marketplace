# Tutor route layout correction

The previous account redesign opted in only the learner/account screens. The owner correctly reported that `/tutor` still displayed the legacy nested card and navigation. Five route-level regression cases reproduced this mismatch before the fix.

The shared shell now applies the reference account layout automatically to `/tutor` and `/tutor/…`, without matching public `/tutors`. Tutor dashboard, My ads, Evaluations and requests share the same external black navigation and coral account header. Header/navigation stay together during scrolling. The new-profile wizard no longer displays three premature Pending cards or an extra numbered About heading inside nested containers. Actual existing-profile progress remains available. The wizard uses the updated coral styling and retains its real private draft workflow. The programmatically focused page container no longer draws the large red outline; interactive controls retain focus indications.

Forty-one targeted UI cases passed across six files, including all five formerly failing routes, onboarding/draft behavior, Tutor workspace, learner dashboard and header navigation. Typecheck and Cloudflare build passed.
