# Local interface fonts

Original Google Fonts Latin WOFF2 subsets, served locally to avoid a render-blocking third-party stylesheet. The font binaries are unmodified; other characters use the existing system fallback. Each font's SIL Open Font License is included alongside it.

- Figtree v9: https://fonts.gstatic.com/s/figtree/v9/_Xms-HUzqDCFdgfMm4S9DQ.woff2
- Outfit v15: https://fonts.gstatic.com/s/outfit/v15/QGYvz_MVcBeNP4NJtEtq.woff2
- Licenses: https://github.com/google/fonts/tree/main/ofl/figtree and https://github.com/google/fonts/tree/main/ofl/outfit
